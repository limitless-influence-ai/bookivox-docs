La page de détail d'une **configuration téléphonique**
(`/telephony-configurations/[identifiant]`) montre ses identifiants et ses
**numéros**.

## La carte de configuration

- Le **nom** de la configuration et un badge **fournisseur** ;
- Un badge **défaut** si c'est la configuration sortante par défaut ;
- La **date de mise à jour**.

Deux actions sont possibles : **Définir par défaut** (pour la sortie) et
**Éditer** la configuration.

## La liste des numéros

Chaque numéro apparaît avec :

| Colonne | Contenu |
| --- | --- |
| **Adresse** | Le numéro (format international) |
| **Type** | Le type d'adresse |
| **Libellé** | Un libellé lisible |
| **Statut** | Actif / inactif, et caller par défaut |
| **Agent entrant** | L'agent qui répond sur ce numéro |
| **Actions** | Définir caller par défaut, Éditer, Supprimer |

## Gérer un numéro

<AccordionGroup>
  <Accordion title="Définir comme caller par défaut">
    Choisissez le numéro utilisé par défaut pour les appels **sortants** de
    cette configuration.
  </Accordion>
  <Accordion title="Rattacher un agent">
    Associez un **agent** à un numéro : les appels entrants sur ce numéro seront
    servis par cet agent.
  </Accordion>
  <Accordion title="Ajouter ou acheter un numéro">
    Sur une configuration **managée Bookivox**, vous **achetez** un numéro. Sur
    un fournisseur externe, vous **ajoutez** un numéro existant.
  </Accordion>
</AccordionGroup>

<Warning>
Supprimer un numéro rompt le routage entrant : vérifiez qu'aucun agent publié
n'en dépend encore.
</Warning>
