## Vue d'ensemble

Vobiz fonctionne comme Plivo, avec une particularité de sécurité importante :
ses webhooks sont **signés sur les octets bruts du corps** de la requête.

## Champs de configuration

| Champ | Requis | Remarques |
| --- | --- | --- |
| `auth_id` | **Oui** | **Account ID** Vobiz (ex. `MA_XXXXXXXX`), masqué |
| `auth_token` | **Oui** | Stocké chiffré |
| `application_id` | Optionnel | **Auto-créée** si absente |
| `from_numbers` | - | **E.164 sans le `+`** |

## Configuration

<Steps>
  <Step title="Récupérer votre Account ID">
    Dans la console Vobiz, copiez l'**Account ID** et le **Auth Token**.
  </Step>
  <Step title="Sélectionner Vobiz">
    Dans **Configurations téléphoniques**, choisissez **Vobiz**.
  </Step>
  <Step title="Saisir les identifiants">
    Renseignez `auth_id` et `auth_token`. Laissez `application_id` vide pour
    une **création automatique**.
  </Step>
  <Step title="Associer les numéros et l'agent">
    Numéros **sans `+`**, puis le workflow **publié**.
  </Step>
</Steps>

## Spécificités techniques

- **Base API** : `https://api.vobiz.ai/api`.
- **Signature** : les webhooks sont signés sur les **octets bruts du corps**.
  Bookivox vérifie cette signature avant de traiter l'appel.
- **Routage entrant** : l'`answer_url` de l'application est mise à jour
  (`answer_method: POST`).
