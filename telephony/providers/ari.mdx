## Vue d'ensemble

ARI (Asterisk REST Interface) branche Bookivox directement sur votre propre
serveur **Asterisk**. La particularité d'ARI est son transport : Bookivox
établit une **connexion WebSocket** persistante vers votre serveur ARI.

## Champs de configuration

| Champ | Requis | Remarques |
| --- | --- | --- |
| `ari_endpoint` | **Oui** | URL de votre endpoint ARI |
| `app_name` | **Oui** | Nom de l'application ARI (Stasis) |
| `app_password` | **Oui** | Mot de passe ARI, stocké chiffré |
| `ws_client_name` | Optionnel | Nom du client WebSocket (défaut : chaîne vide) |
| `from_numbers` | - | Affiché comme « From Extensions » |

## Configuration

<Steps>
  <Step title="Préparer Asterisk">
    Activez l'interface ARI dans votre `ari.conf` et créez un utilisateur dédié
    avec un mot de passe.
  </Step>
  <Step title="Sélectionner ARI">
    Dans **Configurations téléphoniques**, choisissez **ARI**.
  </Step>
  <Step title="Saisir les identifiants">
    Renseignez `ari_endpoint`, `app_name` et `app_password`. `ws_client_name` est
    optionnel (par défaut une chaîne vide).
  </Step>
  <Step title="Associer les extensions et l'agent">
    Les numéros sont présentés comme des **extensions** (« From Extensions »), puis
    sélectionnez le workflow **publié**.
  </Step>
</Steps>

## Spécificités techniques

- **Transport** : Bookivox établit une connexion ARI **WebSocket** persistante
  vers votre serveur ; vous n'avez aucune route HTTP à exposer de votre côté.
- **Authentification** : la connexion s'appuie sur vos identifiants ARI
  (`app_name`, `app_password`), sans signature de webhook supplémentaire.
- **Numéros** : identifiés comme des **extensions**, sans notion d'account-id.
- **Credentials** : `app_password` est stocké chiffré et n'est jamais réexposé
  en clair.

<Warning>
  Exposez votre endpoint ARI uniquement sur un réseau de confiance ou via TLS.
  Comme il n'y a pas de signature de webhook, tout accès au WebSocket avec les
  identifiants ARI peut piloter vos appels.
</Warning>
