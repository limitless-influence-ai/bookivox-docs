## Vue d'ensemble

Telnyx fonctionne en mode **Call Control** : Bookivox pilote l'appel via des
appels REST. Une **Call Control Application** est nécessaire ; Bookivox peut la
**créer automatiquement** à l'enregistrement.

## Champs de configuration

| Champ | Requis | Remarques |
| --- | --- | --- |
| `api_key` | **Oui** | Clé API Telnyx |
| `connection_id` | Optionnel | Call Control Application ID, **auto-créée** si absente |
| `webhook_public_key` | Optionnel | **Requis en pratique** : sans elle, les webhooks Telnyx sont rejetés |
| `from_numbers` | - | E.164 |

## Configuration

<Steps>
  <Step title="Créer une clé API Telnyx">
    Dans le portail Telnyx, générez une **clé API**.
  </Step>
  <Step title="Sélectionner Telnyx">
    Dans **Configurations téléphoniques**, choisissez **Telnyx**.
  </Step>
  <Step title="Saisir la clé API">
    Renseignez `api_key`. Vous pouvez laisser `connection_id` vide :
    l'application Call Control sera **créée automatiquement**.
  </Step>
  <Step title="Ajouter la clé publique de webhook">
    Copiez la **clé publique** (portail Telnyx → *Keys & Credentials*) dans
    `webhook_public_key` pour que les événements soient **acceptés**.
  </Step>
  <Step title="Associer les numéros et l'agent">
    Numéros E.164, puis le workflow **publié**.
  </Step>
</Steps>

## Spécificités techniques

- **Base API** : `https://api.telnyx.com/v2`.
- **Call Control** : Bookivox répond et streame via des appels REST.
- L'application créée automatiquement pointe son `webhook_event_url` vers
  `{backend}/api/v1/telephony/inbound/run`.

<Warning>
Sans `webhook_public_key`, la **signature** des webhooks Telnyx ne peut pas être
vérifiée : Bookivox les **rejette** par sécurité.
</Warning>
