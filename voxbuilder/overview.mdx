**VoxBuilder** est le générateur d'agents de Bookivox. C'est l'entrée du menu
**BOOKI LABS**. Vous décrivez ce que doit faire l'agent en langage naturel et
Bookivox construit le workflow à votre place.

## Ce que vous obtenez

Un workflow complet, avec :

- un nœud **Départ d'appel** (l'accueil) ;
- une ou plusieurs **Étapes agent** (le cœur de la conversation) ;
- un nœud **Fin d'appel** (la clôture).

Le résultat s'ouvre directement dans le **canevas** du builder, où vous pouvez
tout ajuster : prompts, voix, outils, documents.

## Quand l'utiliser

- **Prototyper vite** : passez d'une idée à un agent testable en quelques
  minutes.
- **Cadrer la structure** : laissez VoxBuilder poser l'ossature, puis affinez
  nœud par nœud.
- **Éviter la page blanche** : si vous ne connaissez pas encore les nœuds,
  partez de la génération.

<Note>
VoxBuilder et **Nouvel agent → Builder** mènent au même éditeur. Voir
[Créer un agent](/workflow/creating-an-agent).
</Note>

## Décrire un bon objectif

Plus votre description est précise, meilleur est le résultat.

| À préciser | Exemple |
| --- | --- |
| Le rôle | « Assistant de la boutique Fleur & Co » |
| Les tâches | « Renseigne les horaires, prends les commandes » |
| Le ton | « Chaleureux et concis » |
| Les limites | « Ne donne jamais de conseil médical » |
