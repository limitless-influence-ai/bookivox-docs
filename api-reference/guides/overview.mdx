## Les concepts clés

Avant d'écrire du code, retenez quatre briques. Elles reviennent partout dans la
documentation.

<Tabs>
  <Tab title="Agents">
    Un **agent** est un graphe (`workflow_definition`) de nœuds : un point
    d'entrée (`startCall`), un ou plusieurs cœurs conversationnels (`agentNode`),
    une fin (`endCall`). C'est le format décrit dans
    [Workflow (JSON)](/api-reference/guides/workflow-json).
  </Tab>
  <Tab title="Outils">
    Un **outil** est une capacité donnée à l'agent pendant l'appel : appeler votre
    API (`http_api`), raccrocher (`end_call`), transférer un appel
    (`transfer_call`). Voir [Outils (API)](/api-reference/tools).
  </Tab>
  <Tab title="Identifiants">
    Les **secrets** (clés API tierces, jetons OAuth) ne sont **jamais** dans vos
    définitions : ils vivent dans le gestionnaire d'identifiants et sont
    référencés par un `credential_uuid`. Voir
    [Intégrations HTTP (API)](/api-reference/guides/http-api-integrations).
  </Tab>
  <Tab title="Identifiants publics">
    Les ressources (`workflow`, `tool`, `document`, configuration téléphonie) sont
    référencées par des **UUID publics**, jamais par un identifiant interne
    séquentiel.
  </Tab>
</Tabs>

## Par où commencer

<Steps>
  <Step title="Authentifiez-vous">
    Créez une clé API dans [Clés API](/workspace/api-keys) et envoyez-la dans
    l'en-tête `X-API-Key`. Voir [Démarrage rapide](/api-reference/quickstart).
  </Step>
  <Step title="Faites un premier appel">
    Le [Démarrage rapide](/api-reference/quickstart) contient une requête
    complète et un wrapper TypeScript prêt à l'emploi.
  </Step>
  <Step title="Parcourez les concepts">
    [Nœuds (graphe)](/api-reference/nodes), [Erreurs & codes](/api-reference/errors)
    et [Workflow (JSON)](/api-reference/guides/workflow-json) posent le vocabulaire.
  </Step>
  <Step title="Automatisez">
    [Webhooks](/api-reference/guides/webhooks), [Campagnes](/api-reference/campaigns) et
    [Outils](/api-reference/tools) couvrent les cas avancés.
  </Step>
</Steps>

<Warning>
Bookivox ne fournit **pas** de SDK officiel pour le moment. Les exemples
s'appuient sur `fetch` standard et un petit wrapper TypeScript documenté dans le
[Démarrage rapide](/api-reference/quickstart).
</Warning>
