## Qu'est-ce que le mode Revendeur ?

Le mode **Revendeur** permet de **revendre Bookivox en marque blanche** : vos
clients finaux utilisent la plateforme **sous votre marque**, sans voir la
marque Bookivox.

<Info>
Le menu **Revendeur** est visible uniquement pour les rôles **Propriétaire** et
**Admin**.
</Info>

## Le menu Revendeur

| Page | Rôle |
| --- | --- |
| **Tableau de bord** (`/reseller`) | Vue d'ensemble de votre activité revendeur |
| **Clients** (`/reseller/clients`) | Gérer vos clients finaux |
| **Tarifs** (`/reseller/pricing`) | Définir vos prix (modes marge / EUR) |
| **Paiements** (`/reseller/payments`) | Encaisser via Stripe |
| **E-mails** (`/reseller/emails`) | Personnaliser vos e-mails |
| **Marque** (`/reseller/branding`) | Logo, couleurs, nom |
| **Offres** (`/reseller/offers`) | Créer vos offres commerciales |
| **Usage** (`/reseller/usage`) | Suivre la consommation |

<Note>
Les entrées **Utilisateurs** (`/reseller/users`) et **Numéros**
(`/reseller/numbers`) redirigent respectivement vers **Clients** et **Tarifs**
dans l'interface actuelle.
</Note>

## Comment fonctionne la marque blanche

- Vos clients finaux accèdent à une interface **sans mention Bookivox**.
- Le **nom de marque** (« Bookivox ») est remplacé automatiquement par le vôtre
  dans l'interface.
- L'association entre vos clients finaux et votre compte revendeur est gérée
  **côté plateforme** : vous n'avez rien à configurer techniquement.

## Modèle économique

Vous achetez des **crédits** Bookivox et vous les revendez à vos clients avec
votre **marge**. Vous fixez vos prix, vous facturez vos clients, et vous gardez
la relation commerciale.
