## Votre identité en marque blanche

La page **Marque** (`/reseller/branding`) définit l'**identité visuelle**
affichée à vos clients finaux :

- **Logo** ;
- **Couleurs** ;
- **Nom de marque**.

## Comment le nom est appliqué

Le mécanisme de marque blanche **remplace automatiquement** le nom « Bookivox »
par **le vôtre** dans l'interface de vos clients finaux. Vos clients ne voient
donc jamais la marque Bookivox.

<Steps>
  <Step title="Ouvrir Marque">
    Allez dans **Revendeur → Marque**.
  </Step>
  <Step title="Charger le logo">
    Téléversez votre **logo** (formats web classiques : PNG, SVG).
  </Step>
  <Step title="Définir les couleurs">
    Choisissez vos **couleurs** de marque (accent, primaire).
  </Step>
  <Step title="Renseigner le nom">
    Indiquez votre **nom de marque** : il remplacera « Bookivox ».
  </Step>
  <Step title="Vérifier">
    Ouvrez l'espace d'un client pour vérifier le rendu.
  </Step>
</Steps>

<Tip>
Choisissez un **logo lisible en petit** (barre latérale, favicon) et testez le
contraste de vos couleurs sur fond clair **et** sombre.
</Tip>
