## Publier un template

Depuis la Bibliothèque, le bouton **Publier** ouvre un formulaire de publication.
Vous y décrivez votre template : **titre**, **description courte**,
**description**, **cas d'usage**, et le **contenu** partagé.

Deux natures de contenu sont possibles :

<CardGroup cols={2}>
  <Card title="Prompt" icon="message">
    Seul le **prompt** (et les instructions) est partagé : l'utilisateur part
    d'un texte, pas d'un workflow complet.
  </Card>
  <Card title="Agent JSON" icon="file-code">
    Le **workflow complet** est partagé : structure, nœuds, outils.
  </Card>
</CardGroup>

Une fois publié, vous êtes redirigé vers la page de votre template.

## Importer un template

Un template est **importable** lorsqu'il embarque un workflow complet. Le
bouton **Importer** ouvre un dialogue où vous renseignez :

| Champ | Rôle |
| --- | --- |
| **Nom de l'agent** | Le nom du nouvel agent dans votre organisation |
| **Mode dossier** | Sans dossier, dossier existant, ou nouveau dossier |
| **Dossier** | Le dossier cible (selon le mode choisi) |

<Note>
Importer un template **crée un nouvel agent** dans votre organisation. Les
modifications que vous ferez ensuite n'affectent **pas** le template d'origine.
</Note>

Vous êtes redirigé vers la liste **Agents vocaux** une fois l'import terminé.
