Depuis **Agents vocaux**, le bouton **Nouvel agent** propose trois façons de
commencer.

## Builder

Le plus rapide : vous décrivez l'objectif en langage naturel et Bookivox génère
le workflow. Voir [VoxBuilder](/voxbuilder/overview).

## Canvas vide

Vous partez d'une page blanche. Bookivox crée un workflow minimal contenant un
seul nœud **Départ d'appel** : à vous d'ajouter les étapes suivantes.

<Steps>
  <Step title="Choisir Canvas vide">
    Le workflow est créé avec un nœud **Départ d'appel** par défaut.
  </Step>
  <Step title="Ajouter des nœuds">
    Depuis le canevas, ouvrez **Ajouter un nœud** pour poser une **Étape
    agent**, puis une **Fin d'appel**.
  </Step>
  <Step title="Relier et configurer">
    Reliez les nœuds puis renseignez chaque prompt. Voir
    [Le canevas](/workflow/builder-canvas).
  </Step>
</Steps>

## Importer un JSON

Vous chargez une **définition de workflow** exportée depuis un autre agent ou
un template.

- Le fichier doit être au format `.json`.
- Sa structure est **validée** à l'import : un fichier invalide est refusé.
- Un workflow exporté depuis un agent peut ainsi être réutilisé ailleurs.

<Info>
Le format attendu est décrit dans
[Workflow JSON](/api-reference/guides/workflow-json).
</Info>

## Nommer et organiser

Le nom du nouvel agent est préfixé par défaut, puis libre. Vous pouvez
immédiatement le ranger dans un **dossier** (voir
[Agents vocaux](/workflow/overview)).
