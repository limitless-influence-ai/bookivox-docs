Chaque appel passé par un agent produit une **exécution**. Depuis la barre
d'outils du canevas, l'action **Exécutions** ouvre l'historique de cet agent.

## Ce que contient une exécution

Une exécution donne accès à :

- la **transcription** de l'échange ;
- le **résumé** de l'appel (si activé) ;
- les **données collectées** pendant la conversation ;
- le **coût** de l'appel ;
- les **événements** du parcours (nœuds traversés, outils appelés).

## Vue globale

La liste **toutes exécutions confondues** se trouve dans
[Exécutions](/conversations/overview), dans le menu **Piloter**.
