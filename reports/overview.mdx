## Export CSV

Vous pouvez **exporter** les données pour les analyser dans un tableur ou un
outil de BI.

## Analyse qualité

Le nœud **QA** permet une **analyse qualité post-appel** : il évalue les
conversations selon des critères (respect du script, ton, conformité). Les
résultats alimentent les rapports.

<Info>
Le nœud **QA** se configure dans le canevas. Voir
[Nœud QA](/workflow/nodes/qa). Le contenu du rapport exportable se règle par
agent dans ses [réglages](/workflow/agent-settings).
</Info>
