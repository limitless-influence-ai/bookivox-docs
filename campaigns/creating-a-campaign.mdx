Pour créer une campagne, Cliquez sur **Créer une campagne** depuis la page
**Campagnes**.

## Les champs

<Steps>
  <Step title="Nommer la campagne">
    Donnez un **nom** explicite : il apparaîtra dans la liste et les rapports.
  </Step>
  <Step title="Choisir l'agent">
    Sélectionnez l'**agent vocal** (publié) qui réalisera les appels.
  </Step>
  <Step title="Choisir la téléphonie">
    Sélectionnez la **configuration téléphonique** qui émettra les appels.
  </Step>
  <Step title="Fournir les contacts">
    Deux modes possibles :

    - **Fichier CSV** : importez votre liste de contacts ;
    - **Saisie manuelle** : ajoutez les numéros directement dans un tableau.
  </Step>
  <Step title="Régler les paramètres avancés">
    Ajustez la **concurrence**, les **reprises**, le **planning** et le
    **coupe-circuit** si nécessaire.
  </Step>
  <Step title="Enregistrer">
    Validez : la campagne est créée à l'état initial, prête à démarrer.
  </Step>
</Steps>

## Le fichier CSV

Le mode **Fichier CSV** attend une liste de contacts où figure au minimum un
**numéro de téléphone**. Vous pouvez ajouter d'autres colonnes (nom, ville…) :
elles seront disponibles comme variables dans le prompt de l'agent.

<Tip>
Le mode **Saisie manuelle** est pratique pour tester une campagne sur quelques
numéros avant de charger un gros fichier.
</Tip>

## Réglages avancés

| Réglage | Effet |
| --- | --- |
| **Appels simultanés max** | Le nombre d'appels en parallèle |
| **Reprises** | Nouvelle tentative en cas d'absence, d'occupation ou de répondeur |
| **Planning** | Fuseau horaire et créneaux d'appel autorisés |
| **Coupe-circuit** | Arrêt automatique au-delà d'un seuil d'échec |
