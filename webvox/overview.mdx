**WebVox** est l'outil de Bookivox pour **intégrer un agent vocal à votre site
web**. C'est la seconde entrée du menu **BOOKI LABS**.

## Ce que vous configurez

- **L'apparence** du widget (lanceur, position, couleurs, textes) ;
- **Le comportement** (agent utilisé, messages d'accueil) ;
- **Le code d'intégration**, récupéré via un **dialogue d'intégration**, à
  coller dans votre site.

## Récupérer le code

Le dialogue d'intégration fournit un **extrait à copier** dans votre page. Une
fois le code en place, le widget apparaît sur le site et les visiteurs peuvent
parler à l'agent directement depuis leur navigateur, sans numéro de téléphone.
