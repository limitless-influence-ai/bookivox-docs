La page **Fichiers de connaissance** (`/files`) gère la **base documentaire**
que vos agents peuvent consulter pour répondre : catalogues, tarifs,
procédures, FAQ.

## Importer un document

Vous importez vos documents depuis cette page. Une fois envoyé, un document est
**traité et indexé**. Tant que l'indexation n'est pas terminée, il n'est pas
disponible pour les agents.

## Statut de traitement

| Statut | Signification |
| --- | --- |
| **En cours** | Le document est en train d'être indexé |
| **Terminé** | Le document est prêt à être utilisé par les agents |

<Note>
Seuls les documents dont le traitement est **terminé** peuvent être attachés à
un nœud. Voir [Onglet Connaissance](/workflow/node-knowledge).
</Note>

## Où les documents sont utilisés

Les documents ne sont pas globaux : vous les **attachez nœud par nœud**, dans
l'onglet **Connaissance** du dialogue d'édition d'un nœud. Un nœud ne voit que
les documents que vous lui avez donnés.

<Tip>
Privilégiez des documents **sobres et structurés**. Un document clair donne des
réponses plus précises qu'un long document fourre-tout.
</Tip>
